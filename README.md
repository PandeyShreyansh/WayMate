Smart Fog Vision System

Smart Fog Vision System is an AI-powered computer vision project designed to improve visibility and road safety in foggy environments. The system detects fog density, enhances low-visibility images using advanced dehazing techniques, identifies surrounding objects with deep learning, estimates their distance from the camera, tracks moving objects in real time, and provides voice-based alerts to assist drivers.

The project combines Computer Vision, Artificial Intelligence, and Deep Learning to create an intelligent driver assistance system capable of operating in challenging weather conditions. It is suitable for research, intelligent transportation systems, autonomous vehicles, and advanced driver assistance systems (ADAS).

Key Features
🌫️ Real-time fog detection
🖼️ AI-based image dehazing and visibility enhancement
🚗 Real-time object detection (vehicles, pedestrians, traffic signs, etc.)
📏 Distance estimation to detected objects
🎯 Multi-object tracking
🔊 Voice alerts for nearby hazards
📷 Live webcam, USB camera, or Raspberry Pi camera support
⚡ Optimized for real-time performance
🧠 Modular and scalable architecture
📊 Performance logging and FPS monitoring
